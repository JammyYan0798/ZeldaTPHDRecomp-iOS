# TPHD iPad 性能与设备说明

[English](performance.md) · [项目概览](../README.zh-CN.md)

## 帧率模式的含义

游戏模拟每秒执行 30 个逻辑步。60 模式会在逻辑步之间插入一帧，对部分摄像机、模型、材质、粒子和 2D 面板变换做插值；若干特效和动画路径仍以 30 Hz 更新。显示计数或接近每秒 60 次的画面提交，不表示游戏逻辑本身以 60 Hz 运行，也不证明所有场景都能锁定 60 FPS。

保守起步时可关闭插帧，使用 30 模式。如果 GPU 负载较高，可关闭 Native 分辨率，并在游戏显示设置中选择较低的固定渲染倍率。这些只是起始建议，不是针对特定设备测出的最佳设置。

## Native 分辨率与 MetalFX

Native 分辨率根据当前显示 drawable 尺寸和所选纵横比/适配或裁切方式计算游戏内部渲染尺寸，并受项目的边长和像素数限制。drawable 输出尺寸、叠加层倍率文字和内部渲染目标尺寸是不同的数据。

MetalFX 空间缩放是可选的展示阶段处理。只有展示尺寸在宽、高两个方向都大于源纹理，且设备能创建兼容的 scaler 时，代码才会尝试执行。处理失败时会退回普通采样器。保存的偏好或叠加层文字本身，不能证明 MetalFX 在某一帧实际运行。

## TPHD 短时设备观察

一组短时对照在运行 iPadOS 27.0.1 的 M5 iPad Pro 上进行。两次观察都显示相同的岩石/峡谷画面，但未确认该场景的来源。应用以普通方式启动，启动参数和环境变量为空，没有输入；先预热 10 秒，再观察 35 秒。每次在第 600 帧之后保留了 7 个样本。

| 版本 | GPU 耗时中位数 | 渲染 CPU 耗时中位数 | swaps/s 中位数 |
|---|---:|---:|---:|
| Build 16 | 11.6 ms/帧 | 1.83 ms/帧 | 59.7 |
| Build 17 | 11.3 ms/帧 | 1.85 ms/帧 | 59.9 |

缓存叠加层分别显示 302 和 341 个着色器，无法证明两次观察的着色器缓存状态相同。之后一次 Build 16 观察显示不同的村庄/俯视画面和 730 个缓存着色器，因此未纳入这组对照；没有该场景对应的 Build 17 观察。这组短时数据不能证明可重复的优化收益或回退、最低硬件规格，或游戏其他区域的性能。

记录的偏好值为 `nativeResolution=1`、`aspect=1`、`resScale=1.0`、`scaleFilter=2`、`interpFps=60`、`fps60=1` 和 `metalFxSpatial=1`。画面叠加层显示 M5 设备、2420×1668 输出、`2.0x` 文字，以及瞬时 59.75 FPS 读数。没有独立读取有效内部渲染尺寸或逐帧 MetalFX 活动状态；这些文字和偏好不能当作所请求缩放路径已经实际生效的证明。

## 其他观察与限制

- 维护者报告：一次 60 模式游戏过程中，马匹耐力条和对话没有明显闪烁；之后完成存档并返回主屏幕。这是人工确认，不是受控基准。
- 维护者认为 TPHD 比当前《风之杖 HD》移植运行起来更轻松，这是主观体验。没有同场景或同设备的跨游戏基准支持更低的最低硬件要求。
- 另一次普通启动观察持续 35 秒，但没有可发布的完整帧耗时分布、低分位帧数据或物理内存时间序列。
- 已记录的参考设备只有一台运行 iPadOS 27.0.1 的 M5 iPad Pro。项目 iOS 部署目标为 17.0，但这里没有确认其在 iOS 17 设备上的运行情况。最低 iPad 型号、A 系列代际和物理内存门槛均未知。
- 全流程游玩、所有实体手柄按键、震动、自适应 R2、长时间性能和热稳定性仍待验证。
