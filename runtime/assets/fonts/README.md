# Settings font

`WWHDSettingsSansSC-Regular.ttf` is a static Noto Sans SC Regular subset made from the [official Google Fonts variable font](https://github.com/google/fonts/blob/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf) at weight 400. It covers the settings UI text and the default Latin range.
